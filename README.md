## 🎯 Objetivos de Aprendizagem

- ✅ Aplicar os conceitos aprendidos em um ambiente prático real.
- ✅ Documentar processos técnicos de forma clara, estruturada e acessível.
- ✅ Utilizar o GitHub como ferramenta de versionamento e compartilhamento de documentação técnica.

---

## 📘 Descrição do Projeto

Este repositório contém a **documentação completa da criação e configuração de uma máquina virtual no Microsoft Azure**.  
Todo o processo foi baseado nas vídeo-aulas do curso, com foco em:

- Configuração de ambientes em nuvem.
- Criação e gerenciamento de máquinas virtuais.
- Boas práticas de documentação e uso do GitHub.

---

## 🛠️ Passos Realizados

### 1. Criação da Máquina Virtual (VM)
- Acesso ao [Portal do Azure](https://portal.azure.com)
- Seleção da imagem do sistema operacional (Windows Server)
- Definição do tipo de instância (CPU, RAM, disco)

### 2. Configuração de Rede e Segurança
- Criação do grupo de recursos e da rede virtual
- Abertura da porta RDP para acesso remoto
- Configuração do NSG (Grupo de Segurança de Rede)

### 3. Acesso e Validação
- Conexão remota via RDP
- Validação do funcionamento do sistema
- Testes de conectividade e desempenho

### 4. Documentação Técnica
- Desenvolvimento deste `README.md`
- Organização dos arquivos no repositório
- (Opcional) Inclusão de capturas de tela na pasta `/images`
